# 🤖 [[KioT Hardware]] • Nodos de Campo Mecatrónicos IP65

> Nodos de sensórica y actuación diseñados por [[AGROTECH]] para resistir el polvo, el barro y la amplitud térmica maulina (-5°C a +40°C), transmitiendo microclima en tiempo real hacia [[Agritwin]].

---

## 🛠️ Especificaciones Mecatrónicas

* **Gabinete**: Estanco IP65 resistente a radiación UV, fabricado con PETG técnico.
* **Microcontrolador**: ESP32 Dual Core 240MHz con Deep Sleep (<15μA).
* **Conectividad**: LoRaWAN 915 MHz (alcance 10+ km) + WiFi Mesh local de alta velocidad.
* **Energía**: Celda LiFePO4 de 2600 mAh recargada por mini panel solar monocristalino de 3W con cargador MPPT.
* **Sondas**: Temperatura sumergible DS18B20 (±0.5°C), humedad capacitiva V1.2 anticorrosión, barómetro BMP280 y sensor de mojadura foliar.
* **Actuadores**: Relé de estado sólido para apertura de electroválvulas de riego y sirena de alarma antiheladas de 110 dB.
